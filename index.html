    The whole instruction set
    
    
    
      
    MOV dst, srcCopy a value. Either side can be a register, [address] or [register]; the source can also be a number.
    
      
    ADD SUB AND OR XORRegister with a register or number. Result goes to the first register and sets the flags.
    
      
    CMP a, bCompare without storing. Zero is set when equal, Carry when a is smaller than b.
    
      
    INC DEC SHL SHR NOTOne register. Shifts move the lost bit into Carry.
    
      
    JMP JZ JNZ JC JNCJump to a label: always, or when Zero / Carry is set / clear.
    
      
    PUSH POP CALL RETThe stack starts at 0xDF and grows downward.
    
      
    OUT OUTCPrint a value as a number, or as a character.
    
      
    HLT NOPStop the machine; do nothing.
    
      
    DBPlace raw bytes or a "string" in memory. Numbers: 42, 0x2A, 0b101010, '*'.
    
    
    
    
    Registers A, B, C and D hold one byte each. Addresses 0xE0 to 0xFF are the screen: two bytes per row, one bit per pixel. A semicolon starts a comment.
